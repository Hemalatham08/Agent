# Common Documentation Questions

## Does the documentation show current stock?

No. Stock levels change continuously and are read from the ERP database with
the ERP tools. Documentation defines what stock terms mean.

## Can documentation answer how many products exist?

No. Product counts are live values. Documentation can explain what a product
and a SKU are, but the count itself comes from the ERP database.

## Where are workflows described?

Workflow pages describe the conceptual sequence of steps and the documents
created at each step. The current state of those documents is live data.

## Why do some pages repeat the live-data warning?

The warning is deliberate. It reminds readers that a definition is not a
measurement and that operational questions need an ERP query.

## How are documentation pages updated?

Pages are reviewed, versioned, and updated as the business process changes.
Each page carries a version and an update date so readers can judge how current
the explanation is.
